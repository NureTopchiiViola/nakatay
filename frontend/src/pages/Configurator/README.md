# Конфігуратор автомобіля

Маршрут: `/create`, пункт «Створити» в наявній навігації.

## Компоненти

- `Configurator.tsx`: вкладки, вибір оснащення, кошторис, локальна чернетка, посилання та специфікація.
- `configuration.ts`: довідники за макетом, нормалізація параметрів, сумісність та розрахунок ціни.
- `CarViewer.tsx`: режими перегляду, ракурси, скидання та повний екран.
- `CarScene.tsx`: Three.js, камери, OrbitControls, освітлення, очищення ресурсів та помилки WebGL.
- `buildCar.ts`: оригінальна процедурна демонстраційна модель кабріолета.
- `loadCarModel.ts`: завантаження PBR-моделі, нормалізація масштабу та перекраска кузова.
- `Configurator.css`: адаптивна верстка; зміни стилю Header обмежені маршрутом конфігуратора.

## Перегляд

У 3D працюють обертання мишею/дотиком, наближення колесом/жестом, ракурси та повний екран.
Після фокусування canvas стрілки обертають камеру, `+`/`-` змінюють наближення.
2D використовує ортографічну камеру з фіксованим ракурсом тієї ж моделі: це рендер, а не фотографія.
Вкладка інтер’єру перемикає камеру на салон.
3D-модуль завантажується окремим chunk лише під час відкриття конфігуратора.

Основна модель — наданий користувачем `base_basic_pbr.glb`, локальна копія:
`public/models/horizon-pbr.glb` (приблизно 25 MiB, 500 000 трикутників).
Версія PBR використовує карти кольору, нормалей та metallic/roughness; shaded-варіант
із запеченим освітленням не додається до застосунку. Оригінали залишаються без змін.

Модель містить один mesh та один матеріал з атласом текстур. Перекраска виділяє червоні
ділянки атласу шейдерною маскою, зберігаючи темні деталі. Це приблизна маска,
а не окремий матеріал кузова: інші насичено-червоні деталі також можуть змінити колір.
Початковий червоний колір використовує оригінальну текстуру без перекраски.

Для цієї GLB немає окремих дисків, салону чи змінних деталей, тому їх вибір оновлює
кошторис, але не геометрію GLB. Під переглядачем є пояснення та явний перемикач
«Демо з модифікаціями». У демомоделі колір, диски, салон, декор, дах, фари та спойлер
змінюють геометрію/матеріали як раніше. Для всіх модифікацій на основній моделі потрібен
поділений на деталі GLB з окремими матеріалами кузова та салону.

Завантаження GLB має індикатор, повторну спробу та скасування запиту при перемиканні
моделі чи виході зі сторінки. Текстури, ImageBitmap і GPU-ресурси звільняються при очищенні.

## Межі інтеграції

Ціни та оснащення — локальні дані з макета. Спойлер доступний тільки з `Sport Track Pro`;
при виборі іншого пакета його ціна та геометрія прибираються.

«Зберегти» записує чернетку лише в localStorage цього браузера, без прив’язки до акаунта.
Відновлення доступне окремою кнопкою під підсумковими картками.
«Поділитися» формує URL з валідованими параметрами; серверне збереження для нього не потрібне.
Кнопка заявки відкриває специфікацію з можливістю завантажити JSON. Заявка не надсилається.
Промокод не застосовує знижку: форма повідомляє про необхідність підключення сервера.

Серверні API для конфігурацій, актуальних цін, авторизації, заявок та перевірки промокодів
у поточному backend ще не реалізовані. Перед оформленням реальних заявок сервер має самостійно
перевіряти сумісність та перераховувати ціну за своїми довідниками.

## Перевірки

З каталогу `frontend`:

```sh
npm run build
npm run lint
npm run test:configurator
```

Тести використовують вбудовану підтримку TypeScript у Node.js 22.18+; перевірено на Node.js 24.
Вони покривають розрахунок, сумісність пакета/спойлера, відновлення URL та некоректні вхідні дані.
