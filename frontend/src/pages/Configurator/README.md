# Конфігуратор автомобіля

Маршрут: `/create`, пункт «Створити» в наявній навігації.

## Компоненти

- `Configurator.tsx`: вкладки, вибір оснащення, кошторис, локальна чернетка, посилання та специфікація.
- `configuration.ts`: довідники за макетом, нормалізація параметрів, сумісність та розрахунок ціни.
- `CarViewer.tsx`: режими перегляду, ракурси, скидання та повний екран.
- `CarScene.tsx`: Three.js, камери, OrbitControls, освітлення, очищення ресурсів та помилки WebGL.
- `buildCar.ts`: оригінальна процедурна демонстраційна модель кабріолета.
- `loadCarModel.ts`: завантаження PBR-моделі, нормалізація масштабу та перекраска кузова.
- `bmwCustomization.ts`: процедурні варіанти змінних дисків та перемикання LED-фар.
- `bmwCabin.ts`: допрацьований процедурний салон, прилади та матеріали оздоблення.
- `bmwEquipment.ts`: закріплене дзеркало, камери реєстратора та демонстраційне обладнання Night Vision.
- `Configurator.css`: адаптивна верстка; зміни стилю Header обмежені маршрутом конфігуратора.

## Перегляд

У 3D працюють обертання мишею/дотиком, наближення колесом/жестом, ракурси та повний екран.
Після фокусування canvas стрілки обертають камеру, `+`/`-` змінюють наближення.
2D використовує ортографічну камеру з фіксованим ракурсом тієї ж моделі: це рендер, а не фотографія.
Вкладка інтер’єру перемикає камеру на салон.
3D-модуль завантажується окремим chunk лише під час відкриття конфігуратора.

Основна модель — `1999 BMW E46 328i Sport` автора **Ddiaz Design**:
- Джерело: https://sketchfab.com/3d-models/1999-bmw-e46-328i-sport-5fce3b693344450380b0112a4d21cfe5
- Автор: https://sketchfab.com/ddiaz-design
- Ліцензія: [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).
- Локальний файл: `public/models/bmw-e46-328i-sport.glb`.
- Повідомлення про авторство та ліцензію: `public/models/bmw-e46-LICENSE.txt` і блок під переглядачем.

GLB скопійовано без змін; адаптації виконуються у переглядачі: масштаб, орієнтація,
колір кузова, змінні диски, розділення оббивки та оздоблення салону.
Використання моделі — лише некомерційне, із зазначенням автора, джерела та ліцензії;
адаптації моделі поширюються за тією ж ліцензією. Це не змінює ліцензію коду застосунку.

Модель має 49 мешів, 17 матеріалів і 35 336 трикутників; розмір — приблизно 6,34 MiB.
Кузов перекрашується через окремий матеріал `BMWphong2SG1`, без шейдерної маски.
Стандартний варіант дисків використовує оригінальну геометрію BMW. Для Forged Performance
та Carbon Aeromesh створено процедурні диски з різною кількістю та формою спиць.
Шини й тормозні механізми зберігаються; альтернативні диски розміщуються за реальними
межами кожного колеса. Загальний діаметр колеса не змінюється.

Спрощений оригінальний меш салону прихований. Усередині кузова встановлено процедурний
салон з округлою панеллю, приладами, дефлекторами, радіо, кліматом, кермом, центральною
консоллю, сидіннями та дверними картами. Прилади мають окрему Canvas-текстуру. Це стилізована
доробка для конфігуратора, а не точне відтворення заводського інтер’єру BMW.
Для оббивки доступні чорний, коньячний та світлий матеріали; вставки перемикаються між
карбоном і деревом. Додаткове світло працює лише при огляді салону. Зовнішній кузов,
хром і колеса зберігаються.

Інші візуальні опції залишаються доступними через «Демо з модифікаціями».
Демомодель залишається процедурним кабріолетом.

Опція Matrix LED додає холодне біле світіння лише переднім фарам BMW; задня оптика,
поворотники та протитуманні фари зберігають вихідний вигляд. При вимкненні опції світіння
прибирається. Це візуальна імітація LED-оптики, без симуляції адаптивного світлового пучка.

Панорамний дах недоступний для BMW: вимкнений у формі й видаляється під час нормалізації
URL та чернеток, тому не впливає на кошторис. Night Vision перемикає камеру на решітці
та екран з позначкою DEMO; реєстратор — передню та задню камери з кріпленнями.
Це 3D-візуалізація, без реальної тепловізійної зйомки, розпізнавання людей чи запису відео.
Залишок оригінального дзеркала видалено тільки з його ділянки спільного меша скла;
нове дзеркало з’єднане кронштейном із майданчиком на лобовому склі.

Завантаження GLB має індикатор, повторну спробу та скасування запиту при перемиканні
моделі чи виході зі сторінки. Текстури, ImageBitmap і GPU-ресурси звільняються при очищенні.

## Межі інтеграції

Ціни та оснащення — локальні дані з макета. Спойлер доступний тільки з `Sport Track Pro`;
при виборі іншого пакета його ціна та геометрія прибираються.

«Зберегти» записує чернетку лише в localStorage цього браузера, без прив’язки до акаунта.
Відновлення доступне окремою кнопкою під підсумковими картками.
«Поділитися» формує URL з валідованими параметрами; серверне збереження для нього не потрібне.
Кнопка заявки відкриває специфікацію з можливістю завантажити JSON. Заявка не надсилається.
Промокод не застосовує знижку: форма повідомляє про необхідність підключення сервера.

Серверні API для конфігурацій, актуальних цін, авторизації, заявок та перевірки промокодів
у поточному backend ще не реалізовані. Перед оформленням реальних заявок сервер має самостійно
перевіряти сумісність та перераховувати ціну за своїми довідниками.

## Перевірки

З каталогу `frontend`:

```sh
npm run build
npm run lint
npm run test:configurator
```

Тести використовують вбудовану підтримку TypeScript у Node.js 22.18+; перевірено на Node.js 24.
Вони покривають розрахунок, сумісність пакета/спойлера, відновлення URL та некоректні вхідні дані.
Також перевіряються габарити нових дисків і салону та незалежність оббивки від матеріалу приладів.
